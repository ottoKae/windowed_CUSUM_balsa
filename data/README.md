# Data for the method and examples

The real study data are published as [V1.0.0 on Zenodo](https://doi.org/10.5281/zenodo.24223182). The four archives contain the FC001 balsa inventory, harvest references, monthly VV/VH trajectories and frozen pixel/TDA/STP results. See the [English](../dataset/README.md) or [Chinese](../dataset/README_ZH.md) dataset guide.

For a local replay, extract the archives together into `data/local/zenodo/`. This keeps downloaded arrays and boundaries out of Git and separate from the dataset documentation. The resulting input directory is `data/local/zenodo/dataset/`.

This GitHub directory contains only:

- `demo/`: invented monthly sequences and reference dates, plus their generator;
- `schemas/`: descriptions of data formats used by the scripts.

The complete synthetic example is generated by `scripts/run_current_pipeline.py`; it runs the actual detector, TDA and STP without downloading data. The older stand-month CSV examples in `demo/` illustrate their own schema and are not pixel arrays for that runner.

In the author workspace, `local/`, `private/`, `restricted/`, `capsules/` and the other unlisted data folders retain downloaded inputs, historical caches and release records. They are ignored by Git. Published numerical derivatives can be obtained from Zenodo; original PlanetScope imagery, raw SAR bursts and private interpretation notes are not included in that deposit.

Keep missing observations as missing, and preserve the row order shared by pixel tables and arrays. The [reproduction guide](../docs/REPRODUCIBILITY.md) describes the current input format.
