# Historical representation/configuration figure inputs

These previously prepared, non-identifying aggregate tables support the existing
manuscript figure `fig07_representation_configuration.pdf`. They describe the
historical method/evaluation versions named in their rows. Their precision and F1
columns are **not** the current W36+B20 probability precision or overall F1.

The current figure's source chain and rebuild limitations are documented in
`provenance/figures/figure_bindings.csv` and `figure_dependencies.csv`. Inclusion
of these existing tables supplies source data for that historical figure only;
it does not update the figure or the manuscript and does not certify exact layout
reproduction. Current final accuracy aggregates are in
`results/final_reference_score_20261015/`.
