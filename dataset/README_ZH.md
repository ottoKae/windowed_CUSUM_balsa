# 厄瓜多尔巴沙木林分、采伐参考与月度 Sentinel-1 空间时间序列

**数据集许可：CC BY-NC-SA 4.0；配套代码：MIT。** V1.0.0 已于 2026-11-14 在 [Zenodo](https://doi.org/10.5281/zenodo.24223182) 公开发布。七位作者的 ORCID 和顺序与手稿一致，来源署名见 `LICENSES.md`。复现时引用版本 DOI：10.5281/zenodo.24223182。已上传附件保留打包时的发布前表述，文件内容与校验值保持不变。

这套数据让读者把“哪片林地”“这片土地每个月的雷达观测”和“记录过哪些采伐月份”对应起来，并重新运行论文的检测和林分聚合。

## 数据放在哪里，怎么打开？

四个压缩包解压到同一个位置，合并成一个 `dataset/` 文件夹：

| 位置 | 内容与用途 |
|---|---|
| `inventory/stands.gpkg`、`stands.csv` | 3,498 个库存林分的边界和属性；可用 QGIS 打开，通过 `sample_id` 连接 |
| `cohorts/` | 3,364 个推理林分、459 个有年月参考的林分名单 |
| `references/harvest_events.csv` | 1,049 条采伐参考，可直接用表格软件查看 |
| `timeseries/reference_stands/` | 459 个林分的 25,555 个固定像元，适合先复现精度 |
| `timeseries/national_stands/` | 全国 151,549 个固定像元的完整时序 |
| `products/` | 像元检测、TDA 父报告、STP 分组和林分历史 |
| `reproduction/` | 冻结参数、5,000 次 bootstrap 抽样和 STP 随机化复现材料 |
| `examples/` | 三个案例、每个两个像元的可读 CSV 和曲线 PDF |

459 个参考林分是全国推理范围的子集，不是另一套编号。134 个没有原生像元中心支持的库存林分仍保留，结果为空，不能解释为“没有采伐”。

## 时序怎样对应土地和时间？

一个数组行就是 `units.csv` 同一行的像元，一个数组列就是 `calendar.csv` 同一行的月份。VV、VH 都是 dB；2016 年 1 月至 2026 年 6 月共 126 列，正式报告期为 2017—2025 年。缺测仍为 NaN，不补零、不挪动月份。有效性和原始观测计数另存。

像元通过 `membership.csv` 归属于固定林分。不同轨道的像元保留自己的身份、坐标系和格网，不能因为位置相近就合并。不要单独排序像元表，否则数值会对应到错误的土地。`pixel_track_id` 还用于保持原检测器的置换随机编号。

## 怎样接入脚本？

英文 `README.md` 提供可复制的两条命令：第一条从参考林分时序重新运行 windowed CuSum → TDA → STP，第二条用相同的 1,049 条参考和 bootstrap 抽样计算评价。换成 `national_stands` 即可运行全国范围。使用配套仓库的环境；结果写入新的目录，不覆盖冻结数据。

参考范围的预期结果为 1,208 个 TDA 报告、945 条匹配、495/590 对相邻参考采伐被找回。全国冻结结果为 6,303 个 TDA 父报告。STP 子组不增加采伐次数。实际复现是否通过，以附带验收记录为准。

STP 的复现材料还保留了历史 1,216 个父报告的校准顺序，其中涉及参考子集以外的九个旧林分。其用途是重放随机数顺序，不是扩充参考标签。只运行任意小子集时，新增报告之前的随机序列和描述性 q 值的计算范围可能变化。

## 日期要怎样理解？

参考日期的原始语义保留：1,045 条是历史报告月，4 条明确是光学首次可见冠层移除月。数据整理不改变它们的含义。

TDA 首末月表示检测范围，不代表已经确认的作业持续期。评价采用“参考月 ±1 月”与 TDA 检测范围重叠，并一对一匹配。代表月是来源像元—月份日期的中位数，半月取后一个月。相邻采伐间隔另按同一林分相邻 TDA **首月减首月**保存，避免和代表月间隔混淆。
